# Hero Background Image

## Image File
Place your Palm Jumeirah aerial image file in this directory with the filename:
**`hero-palm-jumeirah.jpg`**

## Image Specifications
- **Format**: JPG or JPEG (recommended for large images)
- **Recommended size**: 2000px width or larger
- **Aspect ratio**: 16:9 or similar wide format
- **File size**: Optimize to under 500KB for web performance

## Image Description
The image should be:
- Aerial panoramic view of Palm Jumeirah in Dubai
- Captured during sunrise or sunset with warm gradient sky
- Shows the palm-shaped island with turquoise waters
- Dubai skyline visible in the background
- Golden/orange/pink/purple sky gradient
- High quality, professional photography

## Fallback
If the image file is not found, the component will automatically fall back to a default Unsplash image.
